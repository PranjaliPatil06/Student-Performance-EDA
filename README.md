# Student Performance EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on student performance datasets using Python and Jupyter Notebook.
The analysis helps understand how different factors affect student academic performance.

---

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

---

## Dataset Used

* student-mat.csv
* student-por.csv

---

## Features of the Project

* Data Cleaning
* Statistical Analysis
* Correlation Analysis
* Data Visualization
* Performance Comparison
* Graphical Insights

---

## Visualizations Included

* Bar Charts
* Histograms
* Heatmaps
* Count Plots
* Scatter Plots
* Box Plots

---

## Objective

The main objective of this project is to analyze student performance data and identify factors that influence academic results.

---

## Conclusion

The project provides meaningful insights into student performance patterns using exploratory data analysis techniques and visualizations.

---

## How to Run

1. Open the notebook in Jupyter Notebook
2. Install required libraries
3. Run all cells
